
# Python Assignment

## Overview

This repository contains solutions to three Python programming questions assigned during today's session.

## Programs

### 1. Numbers Divisible by 7

Write a Python program to find all numbers between 2000 and 3200 (inclusive) that are divisible by 7 but are not multiples of 3. Print the results as a comma-separated sequence.

**Concepts Used:**

* For loop
* Conditional statements
* Modulus operator
* Print formatting

### 2. Convert a List of Characters into a String

Write a Python program to convert a list of characters into a single string.

**Example:**

Input:

```python
["C", "O", "D", "I", "N", "G"]
```

Output:

```text
Coding
```

**Concepts Used:**

* Lists
* Strings
* `join()` method
* `capitalize()` method

### 3. Dictionary of Squares

Write a Python program that accepts an integer `n` and generates a dictionary containing numbers from 1 to `n` as keys and their squares as values.

**Example:**

Input:

```text
5
```

Output:

```python
{1: 1, 2: 4, 3: 9, 4: 16, 5: 25}
```

**Concepts Used:**

* Dictionaries
* For loops
* User input
* Arithmetic operations
